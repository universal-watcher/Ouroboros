# Política de Privacidad de Ouroboros

Última actualización: [26 de mayo de 2026]

Ouroboros es una aplicación de Discord que muestra información relacionada con jugadores y servidores de Minecraft a partir de datos públicos, APIs externas y datos proporcionados por el usuario.

La función principal del bot es generar una vista visual similar a la pantalla que un usuario podría observar al intentar ingresar a un servidor de Minecraft usando un nickname dado. Esto se realiza mediante comandos como `/check` y `/fastcheck`.

## Información que se procesa

Cuando usas Ouroboros, el bot puede procesar:

- Tu ID de usuario de Discord.
- El servidor o canal donde se ejecuta el comando.
- El nickname de Minecraft ingresado.
- El servidor de Minecraft indicado.
- La versión de Minecraft seleccionada.
- Información pública asociada al nickname consultado.

Ouroboros no solicita ni almacena contraseñas, credenciales personales ni acceso a cuentas de Minecraft.

## Seguridad y uso de la información

La información se utiliza únicamente para:

- Ejecutar los comandos solicitados.
- Generar imágenes o GIFs.
- Mostrar información pública relacionada con el nickname y servidor consultado.
- Mejorar el funcionamiento del bot, evitar abuso y mantener estabilidad.

No vendemos datos personales ni compartimos información con terceros.

## Servicios externos

Ouroboros puede consultar servicios externos y APIs públicas para obtener información necesaria, como datos de Minecraft, skins o perfiles públicos.

Estos servicios pueden tener sus propias políticas de privacidad y condiciones de uso.

## Caché y almacenamiento

El bot puede guardar temporalmente ciertos datos para mejorar el rendimiento, evitar consultas repetidas y mantener el servicio estable.

Esto puede incluir caché de imágenes, skins, logos o resultados públicos relacionados con consultas realizadas.

Los datos almacenados se eliminan de forma automática cada 6 horas.
